# kb intake：收進收件匣

收件匣只有 `kb intake` 寫得進去；用檔案工具或指令直接寫會被守門擋（D-046）。收進來的檔照常整理成卡，出處是「對話收件」，卡上多一行 `收件`。

## 一、三種用法

| 情況 | 指令 |
|---|---|
| 拖檔進對話（拿到的是檔的路徑） | `intake "<路徑>"`；原檔名看不出內容加 `--title "<名字>"`（副檔名程式照原檔加） |
| 這一句貼了圖或一段文字 | 先 `intake --pasted list`，再 `intake --pasted image:<n> --title "<名字>"` 或 `intake --pasted text:<n> --title "<名字>"` |
| 程式、skill 交來的 | `intake "<路徑>" --from "<來源名>"`；定期同步同一份加 `--name "<項目名>"` |

- 好幾份一起拖：一次給好幾個路徑，各自一行結果；`--title`、`--name` 一次只收一份。
- 名字（`--title`、`--from`、`--name`）不能有 `\ / : * ? " < > | $` 與反引號，不以點或 `~$` 開頭；貼的東西沒有檔名，`--title` 寫「<日期> <照內容取的名字>」（`2026-10-26 陳經理名片`）。
- 原檔名看得出內容就照用，不給 `--title`；`IMG_2034.jpg`、`下載 (3).pdf`、`scan001.pdf` 這種才自己取，收完說一聲取了什麼名字（D-245）。

## 二、--pasted 從哪裡拿

程式從這一句的對話紀錄取客戶最後那則訊息：圖照原格式存（png、jpg、webp，不轉檔），系統另存了原圖就用原圖；文字取桌面版 `<pasted_content>` 包起來的每一段，沒有這個標記（VS Code、終端機）就取那則訊息的全文。

- `list` 一項一行：`image:1（image/png，12345 位元組）`、`text:1（230 字）`；印「這一句沒有貼圖或文字」就是沒有。
- 只拿得到這一句的；前幾句貼的請她再貼一次或另存成檔再拖。
- 拿不到時程式回那一句（請她另存再拖），照講；不要自己把內容重打一遍存成檔（保證不了一字不差，D-048）。
- 從紀錄取的圖可能被縮過，卡上會標「對話裡的版本」；要列印或存證時請她拖原圖。

## 三、輸出

人讀一份一行，接在最後的「接著整理：kb cards dispatch --json」是有新收或更新、又在對話裡跑的才有；照 ingest 骨架從「拿計畫」往下整理。

| 那一行 | 意思 | 結果（`--json` 的 `result`） |
|---|---|---|
| `收進收件匣了：收件匣/合約.pdf（原檔沒動）` | 拖檔收好了 | `new` |
| `收進收件匣了：收件匣/王先生合約.jpg（原本叫 IMG_2034.jpg）` | 帶 `--title` 收好了 | `new` |
| `收進收件匣了：收件匣/…` | 貼的、定期交來的第一份 | `new` |
| `更新了：收件匣/公司系統/客戶王先生.md` | 定期交來的內容變了，舊的備進回合，卡下次整理重做 | `updated` |
| `沒有變：…` | 定期交來的內容一樣，沒動 | `same` |
| `這份已經在收件匣：…` | 本來就在收件匣 | `already_inbox` |
| `這份我已經在讀了：客戶案件/大安陳/會議紀錄.docx` | 在登記的資料夾裡，不複製 | `reading` |
| `這份收過了：…` | 同一份內容已經在知識庫，不複製 | `have` |

`--json`：`{"items":[{"path","id","result","said"}],"next"}`；`said` 就是人讀那一行，`next` 是要接著跑的指令或 null。被拒的那份 `result` 是 `refused`。

## 四、拒絕句（exit 3，照講）

| 句子 | 怎麼辦 |
|---|---|
| `找不到這個檔：<路徑>` | 路徑打錯或檔已搬走；請她再拖一次 |
| `這份已經在知識庫裡：<相對路徑>` | 不用收；要歸位走 manage 的 `source-edit move` |
| `這個位置你說過不讀` | 那個夾設成不讀，不收；要讀先取消不讀（manage） |
| `這個檔名像密碼或金鑰，不收` | 照講；不換名字硬收 |
| 「檔名不能有 \ / : * ? " < > \| $ 與反引號這些字元」那句 | 換一個名字再跑 |
| `這張圖我拿不到檔；請把它存到電腦，再拖進對話` | 照講；她拖進來後照拖檔收 |
| `這段我拿不到原文；請把它存成檔，再拖進對話` | 照講 |
| `收件匣/<來源>/ 裡已經有同名的檔，不是 <來源> 交的；請先改名或搬走` | 客戶自己放的同名檔，不覆蓋 |
| `--name 要配 --from`、`--pasted 要給 --title`、`--title、--name 一次只收一份` | 參數補齊再跑 |

多份一起收時，被拒的那份一行拒絕句、其他照收，整體 exit 3。

## 五、收完之後

- 收進收件匣最上層的，整理成卡、卡掛了實體，回答末尾 `asks` 會有一題「<卡標題>（收件匣）要放到哪裡？」，結果是那個實體的檔放最多的夾（沒資料夾的客戶是實體夾）與「先放著」；她選了就照那個結果的 `do` 搬（D-244）。
- 她收的時候就說了放哪（「存到王先生的夾」）：整理完直接 `source-edit move "<收件匣/…>" --to "<夾>"`、說一聲，不再問。實體夾還沒建時程式會先建。
- 來源子夾（`收件匣/<來源>/`）裡的是定期交來的，不問放哪；搬走的話下次交來會在收件匣再收一份。
- 不回答就留在收件匣，放太久開場會提醒一次。

## 六、寫給外部程式與 skill

公司系統的擷取程式、排程、別的 skill 要把東西交進知識庫，在知識庫資料夾裡跑：

```
python "<plugin 路徑>/scripts/kb.py" intake "<檔的路徑>" --from "<來源名>" [--name "<項目名>"] [--json]
```

- 一律帶 `--from`（卡上記「從<來源名>」，回答時說「從 X 取回的」，D-242）。
- 同一份會一直更新的（某位客戶的資料、價目表）帶 `--name`：存在 `收件匣/<來源名>/<項目名>`，再交就覆蓋、內容一樣不動，舊的備進回合退得回（D-241）。一次性的不帶。
- 只管交檔，不用自己整理：下次開對話開場會提醒還有幾份沒整理，AI 照常整理成卡。
- exit 0 是收好、沒變或已經有了；exit 3 是被拒（第一行是原因）；其他是程式出錯。
