# 原始碼地圖：hooks

日期：2026-10-30（自 CLAUDE.md 第一節拆出，原文照搬）
給誰看：改這個 repo 的 Claude 與人；要改、要查某個檔時才讀這份。
什麼時候更新：改到表裡某個檔的那個 commit 一起改那一列；新檔加一列。本清單會漂，以 `git ls-files` 為準。

| 路徑 | 用途 |
|---|---|
| `hooks/hooks.json` | 八個 hook 的註冊：SessionStart、UserPromptSubmit、PreToolUse、PostToolUse、Stop、SessionEnd、SubagentStart、SubagentStop（後兩個 matcher `^wiki-with-willy:card-maker$`） |
| `hooks/session_end.py` | SessionEnd（B 段第 6 步）：對話結束把那個對話 open 的整理 job 與批次放掉（`batches.release_ended`，不記 revoked、stopped_turn）；只收 logout、prompt_input_exit、other（matcher 與 `RELEASE_REASONS`），/clear、/resume 交給 last_seen；Claude Code 給 1.5 秒、只 import batches；例外寫 hook-errors.log（source session_end）、永遠 exit 0、不輸出 |
| `hooks/session.py` | SessionStart（startup／resume／clear／compact）：`additionalContext` 先印狀態行（`status_lines`，第一行「【wiki-with-willy】kb 指令」前綴、變動行與找不到來源行共用一次快速 `inventory.scan`、變動行接「實體夾有變 log），空一行再接 `rules/core.md` 全文（D-087）；`ensure_ascii=True`；`line_agenda`：`agenda.counts` 三個數字，0 的項不印、有逾期接「回答末尾跑 kb asks 照著問」，agenda.json 壞了只記 log（日程題）；整理指示照 D-156（先整理、開始前照 `announce` 說一句、整理完再回答）；core.md 檔記著 `ingest_stopped` 就不印整理指示（compact／resume，D-156）；算超過 `UNSORTED_BUDGET`（從 hook 開始 6 秒）不印、寫 log；變動行「還有 N 份沒整理完、M 張卡要跟著搬」（`batches.opening_counts`，0 的那半不印，B-415）；備份還原與換電腦：`line_moved`（排在變動行前面、只讀 `moved.state`、不寫 `vault_path`）印「知識庫換了位置：先跑 kb moved 補好再做別的。」或「這台電腦第一次開這個知識庫：先跑 kb moved 看要補什麼。」，印了就不印整理指示與「找不到來源」兩行；`line_backup` 照留空殼（D-209）；升級打包：`line_version` 排在 kb 行之後、`line_moved` 前面：(a) 換了版要 `--finish`「已換到 X：先跑 kb upgrade --finish 再做別的。」、(b) 上次查到她可以拿的大升級「有新版 X：一句話；說「升級」我帶你做。」（一句話截 `update_note_max` 字）、(c) 清單被指回舊版「這一版 X 撤回了；…」，只用 `env.json` 的 `update_check`、不連網；沒有 `upgrade-history.json` 要做時整理指示不印（跟 `line_moved` 同一處判斷）；歷史壞了那行不印、寫一行 log；lint 題：`start_background_lint`（`kb.lint.runner.opening`：上次健檢超過 `lint_background_days` 天、今天還沒開過就背景開 `kb lint --background`，不等它；環境變數 | `hooks/guard.py` | PreToolUse 守門入口：讀 stdin、呼叫 `kb.guard.decide`，寫 Z1／Z3／Z5 放行前先 `turn.before_write` 備份，印 allow／deny 或不印，永遠 exit 0；守門出錯時知識庫裡一律印 deny（Bash／PowerShell 也是），ledger 記 deny guard_error；card-maker（D-195）：payload 帶 agent_id 而 `turn.agent_turn` 查得到時，寫入備份與大改動算那個回合、放行的單一 kb 呼叫回 `updatedInput`（kb.py 路徑後插 `--turn <回合> --agent <id>`）；主對話（沒有 agent_id）的每個單一 kb 呼叫都插 `--session <sid>`（D-506，#20：寫入記在這個對話的回合、退回只退這個對話的；原本只插 cards dispatch／status／stop、build、intake），已經帶 `--turn` 的不插（#20 裁定 1）；build 第一輪修：記過的子代理認領讀舊 wiki（adopt）批次時，Write／Edit 一律 deny（`batches.adopt_agent`）；桌面版確認修：記過的子代理用寫檔工具寫到知識庫外面一律 deny（`_outside`）；`with_session`：守門回 ask 的密碼動作也插 `--session`（ask 帶 updatedInput，裁定 5），帶 `--password`／`--value` 的不改寫（值不進 hook 輸出，`SECRET_FLAGS`）；帶 `--password`／`--value` 的呼叫放行或 ask 前 `_mark_secret` 直接替 payload 的對話標 secret_shown（裁定 12）；彈性區（D-510）：`BACKUP_ZONES` 多 Z12（寫前備進回合），記過的子代理用檔案工具碰 Z12、或單一 kb 呼叫的參數指到彈性區（`_free_target`）一律 deny；Obsidian首頁（#22，D-255）：`GLOBAL_VALUE_FLAGS` 加 `--via`，模型自己帶照 `SELF_FLAGS` 擋（理由句不改，既有測試比對它） |
| `hooks/turn.py` | UserPromptSubmit：每句話開一個回合，寫 `.system/turns/<sid>.json` 與 `current.json`；先補記上一句的中斷，再寫這一句的日誌開口；上一句中斷且回合記了 `ingest` → 這一句記 `ingest_stopped`、印一次 additionalContext（同 session 之後帶著旗標不再印，D-156）；開頭先刪上一句沒刪到的 `.system/temp/*.secret*`（密碼與守門）；`<agent-message`、`[SYSTEM NOTIFICATION` 開頭也不開回合（card-maker 桌面版 D2）；build 桌面版確認 A 段：建置還沒做完（build.json 的 step 不是 done）時不判「整理被按停止」（回答途中又打一句會被當成中斷）；收件匣：payload 的 `transcript_path` 傳給 `turn.start`（kb intake --pasted 從那裡取貼的東西） |
| `hooks/output_log.py` | PostToolUse：檔案工具寫進 AI 產出後登記到 `inventory.json`；寫進 `檔案索引/` 的 `.md` 卡 `cards.validate`，不過印 decision block（exit 仍 0），過了重寫 `總目錄.md` 與新舊 `實體` 的綜合卡快取；寫進 `<型別>/<名稱>/<名稱>.md` 的綜合卡 `synthesis.validate`，不過 block，過了 `card` 記 true、重渲染快取；payload 帶 agent_id 而 `turn.agent_turn` 查得到時用那個回合（card-maker 釐清 3b）；build 桌面版確認 A 段：綜合卡這一回合備份過時比對舊卡「## 紀事」，出處編號（沒出處的看原句）在新卡紀事裡找不到就 block（紀事只增），有沒清的「不想讓 AI 看到」排除時不比；子代理寫卡時記它認領中批次的 `last_seen`（B 段第 6 步）；D-505：綜合卡驗過之後 `synthesis.copy_tags` 把標籤行抄進實體清單，失敗只記 log |
| `hooks/stop.py` | Stop：AI 答完把這回合的日誌那行補完（結果取 `last_assistant_message` 壓一行遮值再截、做了、改了），只收第一次；回合有 `secret_shown` 結果只記「（這句回答有密碼，沒記）」；收尾一律刪 `.system/temp/*.secret*`；card-maker：這個 session open 或剛關的 job 回合補改了（`journal.refresh_changed`），關了之後第一次 Stop 把派工那句的結果換成這次的最後回答、只換一次（回合記 `job_result`；`secret_shown` 不寫結果）；B 段落差 7：那句還有 open 的 job 先不換，`job_result` 記換結果時的 job 編號，後來又關了一個再換 |
| `hooks/subagent.py` | SubagentStart／SubagentStop（`start`｜`stop`，只認 `wiki-with-willy:card-maker`）：start 記 agents → 回合、回 additionalContext（`session.line_kb` 加 core.md 全文，B-032）；stop 把那個子代理的批次改 done、`journal.refresh_changed`；例外寫 hook-errors.log（source subagent）、永遠 exit 0 |
