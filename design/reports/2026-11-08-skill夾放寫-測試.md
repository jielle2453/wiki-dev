## plugin-dev 審查

依 `plugin-dev:hook-development` 審 `hooks/`：這題只改 `hooks/guard.py` 的 `BACKUP_ZONES` 多一個 `"Z13"` 與 docstring，輸出格式（`hookSpecificOutput.permissionDecision`）、exit code、`hooks.json` 都沒動；守門出錯照舊 fail closed。hook 本身沒問題。另外 hook-development 的事件清單沒提 skill frontmatter 的 hook，這正是 #1 的盲點：守門只看得到 PreToolUse 經過的工具呼叫。

plugin-validator（Sonnet，`claude -p`，照 agent 定義跑整個 repo，0.22 美元）：**PASS，0 個錯誤**，4 個警告都不是這題的改動：`agents/card-maker.md` description 沒有 `<example>`、frontmatter 有 `background: true`；`hooks.json` 的 `onFailure: "block"` 不在它認得的 schema；沒有 `commands/` 夾。validator 自己的 JSON 解析被擋沒跑，我補跑 `json.load`：`plugin.json`、`hooks/hooks.json`、`.claude/settings.json`、`skeleton/.claude/settings.json` 全 ok。
