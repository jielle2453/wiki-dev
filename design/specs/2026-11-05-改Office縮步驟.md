## 做法（不加新子指令，改兩個現有的）

1. **A：`office copy` 自己補記清冊**（`scripts/kb/office_cli.py` `_copy`）
   - 清冊沒有這份、而且路徑在登記的來源裡、檔在：照 `kb inventory scan --source <那個來源>` 同一套（掃那一個來源、apply、記工作日誌程式段）補記，再照原本的判斷給副本。
   - 排除的、像密碼的、不在登記的夾、不見的：照舊擋，句子不變。
   - 要動：把 `inventory_cli._scan` 的「掃＋apply＋記日誌」抽成一個函式給兩邊叫（行為不變）。
2. **B：`office copy --unpack`**（不另開 `office open`）
   - 給副本後接著 `office.unpack`，印兩行：「副本：…」「解開到：…（看內容、改字都在這個夾，用 Grep／Read／Edit）」。
   - 解開時在夾旁邊寫一個小檔 `<夾名>.json`：`{"like": 副本路徑, "from": 原檔清冊編號, "name": 原檔名}`，給第 3 點用。不寫進夾裡（免得被打包進去）。
   - 不是 docx／xlsx／pptx 的檔加 `--unpack`：照給副本，第二行說「這種檔不用解開」。
3. **C：`output save` 收解開的夾**（`scripts/kb/output_cli.py`、`_lib/output.py`）
   - 第一個參數是工作區裡、旁邊有 `<夾名>.json` 的夾時：
     1. 打包：照 `office.pack(..., like=副本)`（沒改的部件逐位元相同）。
     2. 驗（程式做，不過就不放、第一行說原因、exit 3）：
        - 改過的 XML 部件都要能解析（壞掉的 XML 會讓 Word 打不開）。
        - 跟副本比一個部件都沒改：「沒有改到任何東西，沒放」。
        - Word：`word/` 底下改過的部件，作者「AI 助理」的 `w:ins`／`w:del` 要比副本多；沒有就「改了字但沒有用修訂標記（作者 AI 助理），沒放」。
        - Excel：有公式就照 `office.recalc` 重算，錯誤數不是 0 就不放、列出那幾格；沒有重算工具照現在的固定句（公式要她打開才更新），照放。
        - PowerPoint：只驗 XML 能解析（沒有修訂標記；版面照舊靠 `office render`，SKILL 那條不動）。
     3. 放：沒給 `--to` 就放原檔旁「<原檔主檔名>（AI 修改）.<副檔名>」（make.md 現在的規矩）；`--from` 自動是原檔。之後同 `output save`：先留一份、登記、記改自哪份、記工作日誌。
     4. 成功句照 `SAVED`，多一句驗了什麼（例：「修訂 3 處」「重算過，錯誤 0」），AI 照念就是回答要列的改了什麼。
   - 給一般檔時跟現在一模一樣。
4. **D、E、F：說明**（`skills/produce/SKILL.md`、`references/make.md`）
   - SKILL 第 47 行換成上面三步的完整寫法（指令＋參數照寫，省 `--help`），加「看內容 Grep／Read 解開的夾，不用 python」。
   - F「載入文件技能」那句：#40 後 2 次都沒載、willy 的規矩已在 make.md → **建議拿掉**，省下的字給新寫法；請 jacky 定。
   - 本文已 2999／3000 字：新寫法要的字從第 47 行自己（拿掉文件技能、unzip／zip 那段）與 make.md 搬得走的細節縮出來，不加總長。
   - make.md「改她原本的檔」改寫成新流程；Excel 說明改成「save 會自己重算」；舊的 `unpack`／`pack` 從說明拿掉。
5. **G 不做**：`output save` 現在就會記一段工作日誌程式段；`turn note` 是第二題（willy優化）。

## 留著的保護

- 先拿副本：原檔不被改（copy 照舊）。
- `--like`：程式自己用副本打包，AI 不會漏。
- 先留一份、登記、記改自哪份：照 `output save`。
- **多一層**：驗修訂與 XML 交給程式，AI 沒驗也擋得住（現在 4 次都沒驗）。
