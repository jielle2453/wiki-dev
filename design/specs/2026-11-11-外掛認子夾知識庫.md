## 目的

客戶原本就有一個 Obsidian 資料夾（vault），舊筆記、原始檔都在根目錄，willy 的知識庫建在裡面的一個子夾（例如 `willy/`）。她打開的是上層那個 vault，首頁（時間軸、月曆、待辦、搜尋、便條）要照樣能用；同一個 vault 裡有好幾個知識庫時，首頁上方可以選看哪一個。

現在外掛（`obsidian/main.js`）把 vault 根當知識庫根，開在上層就找不到 `.system`，整個首頁不畫。

名詞：
- **vault**：Obsidian 打開的那個資料夾。
- **知識庫根**：有 `.system/sources.json` 的那個夾（kb 的 `guard.find_vault` 認的記號）。
- **前綴**：知識庫根相對 vault 的路徑，分隔用 `/`。vault 根就是知識庫時前綴是空字串 `''`；知識庫在 `<vault>/willy` 時前綴是 `willy`。
- **庫內路徑**：相對知識庫根的路徑（kb 的輸入輸出都是這種）。**vault 路徑**：相對 vault 的路徑（Obsidian 的 API 都是這種）。vault 路徑＝前綴＋`/`＋庫內路徑（前綴空就是庫內路徑）。

## 要做的事

全部在 `obsidian/main.js`、`obsidian/styles.css` 與 `tests/obsidian/`。函式名是建議，實作可以換名字，行為照寫的。

### 一、找知識庫

1. 純函式 `findKbRoots(opts)`（`opts`：`vaultPath`、可換的 `exists`、`readdir`、`isDir`，測試用）回前綴的陣列：
   - vault 根有記號 → 回 `['']`，不往下找。
   - 沒有 → 看 vault 根的第一層與第二層子夾，有記號的收進來，照前綴排序。名字以 `.` 開頭的夾、`node_modules` 不進去；讀不了的夾略過。
   - 記號：`<夾>/.system/sources.json` 是檔案，或 kb 的來源流水檔夾裡有 `*.jsonl`（位置照 `scripts/kb/_lib/streams.py` 的 `stream_dir(vault, "sources")`，實作讀那支抄相對路徑）。
   - 一個夾有記號就不再往它裡面找。
2. 外掛載入（`onload`）與每次開首頁（`activateHome`）各找一次，結果放 `this.roots`。跟上一次不一樣才重畫。

### 二、目前看的知識庫（首頁用）

3. `this.current`：目前選的前綴。載入時：`data.json` 記的 `current` 還在 `roots` 裡就用它，不然用 `roots[0]`；`roots` 是空的就是 `null`。
4. 每個前綴各有一個 kb runner，cwd 是 `path.join(vaultPath, 前綴)`，用到才建。`findKb` 的 `vaultPath` 參數改傳知識庫根的絕對路徑（`projectPath` 比對的是知識庫，不是 vault）。`this.kb(args, root)` 的 `root` 沒給就是 `this.current`。
5. `roots` 是空的：首頁印「這個資料夾裡沒有找到 willy 的知識庫（找了這一層與下面兩層）」，其他區塊不畫。找得到知識庫但找不到 kb：照舊印 `NO_KB_TEXT`。
6. 首頁叫 kb 的全部走 `this.current`：`refresh`（`kb home`）、抽屜（`lookup`）、搜尋（`find`）、加日程與改日期、待辦的選項、`gitRefresh`。
7. kb 回來的庫內路徑（`card_path`、`path`、`page`、`card.path`…）交給 Obsidian 之前一律轉成 vault 路徑：`openPathInVault`、`openAgendaLine`、`openPageLine`、`openSynthesis`、便條的 `NOTE_REL`／`NOTE_DIR`（`adapter.exists／read／write／mkdir`）。
8. 監看：`startWatch`（`.system`）與 `startGitWatch`（`.git`）改成看 `this.current` 那個知識庫根底下的；切換時關掉舊的、開新的。`.git` 只看知識庫夾自己的，上層 vault 的 `.git` 不看（D-546）。

### 三、切換

9. `roots` 超過一個時，首頁最上面（`renderTop` 那一列的最左邊）出現一個下拉選單，列每個知識庫的名字：前綴的最後一段；最後一段重複的顯示整個前綴。只有一個時不出現。
10. 選了別的：先 `flushNote()`（便條還沒存的字寫回**原來那個**庫）→ 換 `this.current`、存進 `data.json` → 抽屜關掉、搜尋清掉、`home` 清空 → 監看重開 → 重讀便條 → `refresh()`。切換中 kb 回來的舊結果不能畫上去（照 `loadDrawer` 的寫法：回來時先比是不是還是同一個庫）。
11. 時間軸縮放、月曆收合照舊整個外掛共用一份，不分庫。

### 四、跟著開著的檔走的動作（D-543）

12. 函式 `rootOf(vault 路徑)`：回包含這個檔的知識庫前綴（`roots` 裡前綴等於它的開頭一段的；`''` 包含全部），沒有回 `null`。
13. 下面這些一律用 `rootOf(那個檔)` 決定叫哪個庫的 kb、並把 vault 路徑去掉前綴成庫內路徑再判斷與傳給 kb；`rootOf` 回 `null` 就什麼都不做：
    - `onFileOpen`、`showPanel`（`kb entity panel`）、`drawPanels`／`buildPanel` 裡點了開頁
    - `isManagedPage`、`isGeneratedPage`、`makeReadOnly`、`addGeneratedBanner`
    - `switchedTo`、`onEditorChange`、`onWindowBlur`、`applyPage`（`kb renders apply <庫內路徑>`）、`saveOpen`
    - `onVaultModify`（「這頁更新了」的提示）
    - `cardPathOf`／`cardTitleOf`／`linkifyCardRefs`／`cardRefExtension`：〔f-…〕只在同一個庫的 `檔案索引/` 裡找；索引每個庫各一份
    - `showPanel` 裡跳過 `系統/`、`檔案索引/` 的判斷改用庫內路徑
    - `this.panels`、`this.applying`、`this.tracker` 的鍵照舊用 vault 路徑（不會撞）
14. 開原檔的 `obsidian://wiki-with-willy-open?id=…`（`openById`）：網址格式不變。從協定進來的，用目前作用中那個檔的 `rootOf`；沒有作用中的檔或不在任何庫裡，用 `this.current`。首頁自己叫的 `openFile`／`openById` 用 `this.current`。
15. `recordOpened` 記進那個庫自己的「最近」（見「資料與介面格式」）。

### 五、在上層時不打擾她的 vault（D-544）

## 資料與介面格式

外掛的 `data.json`（`.obsidian/plugins/wiki-with-willy/data.json`，在外掛所在的那個 vault）：

```json
{
  "current": "willy",
  "roots": {
    "willy": { "opened": [{ "card": "f-1a2b", "at": "2026-11-11T09:00:00.000Z" }] },
    "客戶B/知識庫": { "opened": [] }
  },
  "timelineDays": 14,
  "monthCollapsed": true
}
```

- `roots` 的鍵是前綴（vault 根就是知識庫時是 `""`）。不存絕對路徑（D-019）。`opened` 的規則照舊（D-262：只存卡編號與時間、最多 30 筆、編號要符合 `^f-[0-9a-f]+$`）。
- 舊格式（最上層有 `opened`）：`sanitizeData` 讀到時搬進 `roots[<載入時的 current>]`，下次存檔就是新格式；最上層不再寫 `opened`。
- `roots` 裡已經不在 `this.roots` 的鍵留著不刪（她可能只是暫時搬走）。
- `current` 不是字串、或不在找到的清單裡，當成沒記。
- 丙的 `kb folders purge` 會照這個格式清，兩支要對得上。

kb 的指令、參數、`--json` 輸出都不變。外掛傳給 kb 的路徑一律是庫內路徑。

三支都做完後一起做。確認用的 vault 放 `willy-測試\開發\#66-外掛上層vault\確認vault\`（裡面放兩份假知識庫的複本 `willyA\`、`willyB\`，根目錄另放幾份假的舊筆記與一個同名的 `檔案索引\` 夾），不碰真的知識庫。

2. （人眼）切到 `willyB`：時間軸、月曆、待辦、便條都換成 B 的；搜尋一個只有 A 有的字找不到、只有 B 有的找得到。
3. （人眼）在首頁加一條日程：只有 `willyB\系統\日程.md` 多一行，`willyA` 的沒變。
4. （人眼）首頁留在 B，從檔案樹開 `willyA` 的一張綜合卡：卡底下那段是 A 的日程；點一張檔案卡上的「開原檔」開到 A 的原檔。
