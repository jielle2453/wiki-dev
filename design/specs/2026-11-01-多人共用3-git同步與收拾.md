## 目的

第 1、2 份讓資料可以放 git、知道是誰。這份讓 willy 在 git 同步的環境裡**自己顧好**：pull 之後重畫這台的頁、原檔變了只交給一台整理、git 衝突時不讓同步卡住、退回時不蓋掉別人後來改的、使用者丟進知識庫的大檔不讓 push 卡住、健檢不讓全隊重複做；加上建置時要講的與給服務人員的說明。willy 第一次自己跑 git（只在 kb 程式裡，AI 不經 Bash 跑 git）。原檔與暫存區留在團隊雲端硬碟（D-323、D-324），由雲端自己同步、自己處理兩人同時改；git 裡會衝突的只剩卡與共用檔。

使用者時刻：小王改了雲端硬碟上的規格；老闆的 Obsidian 在背景 pull 下小王那台推上來的口述與日程，日程頁自己更新；雲端同步到老闆那台後兩台都看到規格變了，只有一台整理，老闆那句問到規格時 Claude 說「小王那台在整理，我先照原檔答」；兩人剛好同時糾正同一張綜合卡，git 卡住了 → 老闆下一句話時 Claude 收拾好、同步接著跑，說一句「你跟小王同時改了某某的卡，我留了一版、標成要重做」。

- **設計自定（11-02 對齊時定）**：
  1. **對帳不另比雲端的原檔**：pull 不會動到雲端的原檔，雲端同步進來的變動交給丙每句開頭的檔案比對（跟這台自己改的一樣看）；對帳只對「知識庫 repo 裡的原檔」（沒有雲端硬碟的團隊、使用者丟進知識庫的檔）照新定 2 處理。
  2. **雲端的衝突副本靠 AI 認**：程式不認副本的檔名樣式（OneDrive、Google Drive、NAS 各家不同）；丙比對出的新增檔交 AI 時本來就帶 `shared: true`，AI 看檔名像同夾某份的衝突副本就照 D-295 (2) 問，不替她挑。

- **這份 spec 新定（要使用者看過說可以）**：
  1. **git 只由 kb 程式跑**：新 `_lib/git.py` 一支包起來（逾時、不跳帳密視窗、`index.lock` 重試）；AI 不經 Bash 跑 git（守門現在就把 `git checkout|reset|…` 當寫入擋，不放寬）。
  2. **pull 之後的「修改」只認指紋真的變了**（11-02：只管知識庫 repo 裡的原檔——沒有雲端硬碟、原檔放 git 的團隊（D-323 的例外），或使用者丟進知識庫的檔；雲端的原檔 pull 不動它，見設計自定 1）：git pull 會把動到的檔的修改時間都更新，快速掃描來不及算指紋的會被當「修改」（現在 quick 模式超過預算就這樣算）。對帳時先問 git 這次 pull 動了哪些檔（`git diff --name-only <上次版本> HEAD`），只有這些去算指紋，其他的只更新本機修改時間；**認領與整理只看指紋確定變了的**，「來不及比」的不派工、下一句接著比（丙不跟她報數字）。
  3. **衝突時留哪版**：卡留**對方**的版本（`git checkout --theirs`，剛 pull 進來的那版），自己這邊的放進 D-270 的「她改過」比對（`card_base` 的 `pending`），之後照手改流程變成知識；這樣自己這台的改動不會不見，對方那台也不用再處理一次。其他在 git 裡的檔（骨架檔、知識庫 repo 裡的原檔）：原位留**自己的**、對方的另存「<名稱>（<對方名字>的版本）.<副檔名>」。（雲端的原檔與暫存區不在 git，不會走到這裡。）
  4. **Obsidian git 外掛用 rebase 而不是 merge 時**：willy 不收拾 rebase 到一半的狀態（風險大），每句話開頭說「同步卡住了（rebase 到一半），請聯絡服務人員」（同一個對話講一次，D-327）並寫 `hook-errors.log`；建置的建議設定裡把外掛設成 merge（spike B-524 第 2 項確認外掛有這個設定）。
  5. **標籤的名字**：`willy/claim/<清冊編號>-<指紋前 12 碼>-<YYYYMMDD>`（整理）、`willy/lint/<年>-W<週>`（健檢）、`willy/upgrade/<版本>/<路徑雜湊前 12 碼>`（共用檔改寫）；用 annotated tag，訊息是這台的人名（第 2 份），AI 要講「X 那台在整理」從這裡讀。

1. [ ] `git.py`：不是 repo、沒有 git 時各函式回不適用；`push_tag` 同名第二次回 `taken`；遠端不存在回 `offline`；`index.lock` 存在時重試後成功（測試裡建一個再刪）。

3. [ ] 每句話開頭：HEAD 沒變不叫 refresh（計次）；變了叫一次、在丙的檔案比對之前（看叫用順序）；同時叫兩次只跑一次；`hooks/session.py` 開場不叫 refresh。
