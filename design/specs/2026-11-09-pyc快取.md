1. `git grep -n dont_write_bytecode -- scripts hooks` 沒有輸出。
2. 相關測試全綠（exit 0）。
3. 在 repo 外複製一份 plugin（`git archive HEAD scripts hooks config .claude-plugin`），清掉 `PYTHONDONTWRITEBYTECODE` 後跑 `python scripts/kb.py --help` 一次：`scripts/kb/__pycache__/` 出現 `.pyc`；再跑 3 次，中位數比刪行前（同樣複製、`PYTHONDONTWRITEBYTECODE=1` 跑 3 次）少 0.5 秒以上。數字寫進紀錄。
4. 同一份複製在一個空的假知識庫夾當 cwd 跑 `kb.py version` 與 `echo {} | python hooks/turn.py`：假知識庫夾底下沒有任何 `__pycache__`（`find <夾> -name __pycache__` 沒輸出）。
5. zip 不會帶 .pyc：發行 zip 是 `git archive <tag>` 取的（`release._archive`），`.gitignore` 擋 `__pycache__/`、`*.pyc`。驗：在剛跑過測試、工作區有 `__pycache__` 的 worktree 跑 `git ls-files | grep -c pyc` 得 0。（`allowed()` 本身不擋 .pyc，這題不改它。）
