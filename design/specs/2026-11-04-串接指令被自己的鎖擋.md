## 要做的事
選的做法：不動守門（`hooks/guard.py` 的 `with_session` 照舊只改寫整行單一 kb 呼叫），改成「被當成終端機擋下時，訊息講對原因、叫 AI 單獨一行重跑」，skill 再加一句不要串。放棄：讓守門改寫串接指令插 `--session`（要拆 shell 語法、改寫任意指令，出錯面大，碰守門擋的邏輯要走一般流程）。

1. `scripts/kb/_lib/build.py`：加 `TERMINAL_HINT`；`_claim` 的終端機分支擋下時回 `BUSY` 加 `TERMINAL_HINT`（開頭不變，AI 原句照貼的講法照舊）；`status --takeover` 從終端機來、有對話拿著鎖時也擋（原本無聲回 None、什麼都沒換）。終端機不搶對話的鎖（R3）照舊。
2. `skills/build/SKILL.md`「共通」第一條：加「kb 後面也不接 ; | > 別的指令（串了守門認不出是哪個對話，會被自己的鎖擋）」；骨架第 1 點加「句中有『這一句被當成終端機』是你串了指令，不貼給她，kb 指令單獨一行重跑」（review 後加：原句照貼會把終端機、守門這些詞貼給客戶）。
3. `tests/test_lib_build.py`：加 `test_terminal_refusal_says_why_and_takeover_not_silent`。

## 可以動 / 不可以動
- 可以動：上列三檔、`ops/map-lib-platform.md` 那一列、本 spec。
- 不可以動：`hooks/guard.py`（`with_session`、`kb_args`）、`build.json` 格式、`BUSY` 原句、`_claim` 對話之間的判斷。
- 相關測試：grep `_lib import build`、`skills/build`、`SKILL.md` 等找到的 20 檔（`test_lib_build`、`test_build_round1`、`test_scripts_build_cli`、`test_skill_build`、`test_budget` …）加 `test_repo_hygiene`。

## 驗收準則
1. `python -m pytest -q tests/test_lib_build.py`：對話 A 拿著鎖，終端機（`turn.SESSION=None`）`set` 與 `status --takeover` 都回 Refused，開頭「另一個對話正在建置（訪談，最後動作 」、含「單獨一行」；`build.json` 不變、沒有 `takeovers`。
2. 試用庫複本實跑（主對話）：`kb build status --json` 後跑 `kb build set people "5個人使用"; echo "exit $?"` → exit 3、訊息帶「這一句被當成終端機…單獨一行再跑一次」；接著單獨一行 `kb build set people "5個人使用"` → 過。
3. 相關測試加 hygiene commit 之後全綠。
