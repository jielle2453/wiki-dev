## 做法

1. **`output save` 存 xlsx 自己重算＋驗**（檔、夾都一樣；保護不是做法）：
   - 存的是 `.xlsx` 且有公式：在工作區重算（來源不在工作區就先複製一份進去算，原來那份不動），錯誤值不是 0 就不放，回現有的 `RECALC_ERRORS`「重算後有 N 格是錯誤值，沒放：B1（#REF!）…」，exit 3、什麼都沒動；AI 照位置修好再存。
   - 沒有重算工具（沒 Excel 也沒 LibreOffice）：照放，成功句下一行「驗過：公式要她打開檔案才會更新」（現有句），回答不報公式算出來的數（現有規則）。
   - `.xlsm` 不自動重算（現有 `MACRO_NO_RECALC`，重算程式存檔可能弄掉巨集），照放並說一句。
   - 做法：把夾那條的 Excel 驗抽成一個函式，存檔與存夾都叫它；不加指令、不加參數。
2. **骨架 CLAUDE.md 第 3 行「沒開著的要改」那段換成**（開著那段 #24 不動）：
   > 做 Word、Excel、PowerPoint、PDF：原檔先 kb office copy "<原檔>" --unpack 拿副本，新的在 kb office 工作區做；做好一律 kb output save 放進來（蓋回原檔會留同夾版本檔，最後問要不要刪），匯出、另存也是，不直接寫進知識庫或原檔。
   - 字數：舊 125 字、新 151 字（+26）。常駐合計 5008 → 約 5034，上限 5050（`test_budget`）。
   - 留 `--unpack`：它是參數不是做法；OBS C1 沒寫時 AI 每次多查 4 次 `--help`（約 +85 秒）。
   - 「匯出、另存也是」管 Word COM 匯出 PDF 直寫（B 02）；守門看不到 COM 寫入，先靠這句（issue「先不做」那條照舊）。
3. **`output save "<檔>" --replace` 也同夾留（版本 N）**：目的地已經有同名檔、加了 `--replace` 時，跟存夾一樣走 D-529：舊的複製成同夾「<主檔名>（版本 N）」、回合備份硬連結到它、換上被鎖回「檔案正開著，改視窗裡那份」、成功句同 `OVERWRITTEN`＋問要不要刪那行、`versions items` 併成一項。
   - 退回行為不變：原檔換回、這一句新建的版本檔拿掉；暫存區裡的照成品留著（D-074）。
   - 範圍：所有 `--replace`（原檔、暫存區的每月報表都一樣），不分種類，規則只有一條。沒登記的位置（知識庫外、不在來源裡）照舊沒有回合備份，版本檔照留。
   - make.md 「同一期間改過才算新版，加 `--replace`（舊的先留一份）」改成「（舊的留成版本檔）」。
4. **produce 瘦成保護層**（SKILL 本文、make.md 都縮）：
   - 留（CLAUDE.md 沒有、willy 才有）：分辨（含不是這裡的話）；收資料用哪幾個 kb；草稿跨對話（D-163、draft.md 不動）；用途決定成品與線上文件三件事＋`kb output link`；成品放哪、回答要說的（放哪、退回、用了哪幾份）；數字核對交 `kb tally`；不附內部出處（D-169）；草稿短標；工具不夠先問再裝；不替她寄（R-09）；腳本只寫工作區（`office run` 守門管不到，B-401）；程式回的句子怎麼轉白話（make.md 末兩節）。
   - 拿掉（做法）：PowerPoint 改版面 render 那條原則、make.md 的中文字型、Excel 改法（只改輸入格、不用 openpyxl）、PowerPoint 三級、「放進來前先驗 render／recalc」、改原檔 Grep／Edit XML 的步驟、文件技能腳本在 Windows 不能跑那串的細節（只留一句「這台轉 PDF、重算、解開打包用 kb office」）。
   - 改原檔一節縮成保護：開著改視窗裡那份不備份；關著 copy --unpack → output save；被擋說開著；問刪版本、`kb source-edit trash`。
   - 拿掉骨架末兩行 `kb asks --about…`、`kb turn note…`（跟 #46 一致：kb 指令的白話句程式自己記進回合、lookup 順帶要問的事）。
   - SKILL 本文仍在 3000 字內；description 不動（常駐預算）。
   - **跟 #46 怎麼對**：#46 在 willy優化 分支 `spec/每句少叫`（d0d816c）還沒併，它沒碰 produce，文字不會衝突。但拿掉的兩行要靠 #46 才有替代（asks 跟著 lookup 回、turn note 程式自己記），所以 **#47 併 main 要在 #46 之後**（或同一次併、同版發）；#46 先併，我併 #47 前 pull、重跑 `test_skill_produce` 與 `test_budget`。`test_skill_produce` 骨架那條要的字拿掉 `kb asks`、`turn note`。
5. **kb office 子指令**：照 9c 這次都不拿。
   | 子指令 | 留的理由 |
   |---|---|
   | check、setup | 印工作區、裝工具到工具夾（要問她，原則留） |
   | copy、unpack、pack | 保護入口；C1 沒寫做法時 AI 自己找回 unpack／pack（守門擋 unzip、zipfile） |
   | run | 工具夾的 node／python 套件只有經它找得到；腳本只寫工作區 |
   | pdf | 這台內建 pdf 技能不會 Word 轉 PDF；不用它 AI 會走 Word COM 直寫（B 02） |
   | recalc | output save 內部用；AI 存檔前想讀算好的數字核對也用得到 |
   | render | 只剩看版面用，make.md 不再教；拿掉要改程式、測試、說明，省不到東西，拿不準就留 |
