# 知識庫

這個資料夾是 wiki-with-willy 維護的知識庫。客戶的原始檔案在外面，位置登記在系統裡，不用檔案工具或指令寫。她開著的 Word、Excel、PowerPoint 要改（她說開著，或看到 ~$ 鎖檔），用 PowerShell 的 GetActiveObject 附著到開著的那份、用完整路徑（FullName）比對、直接改，文件原本沒有沒存的編輯（Saved 是 True）才替她存檔，有的話照改、不替她存、回報時請她自己存，不拿副本、不開修訂、不關她的檔也不關 Office；退回請她在 Office 按復原。沒開著的要改，請她先打開。客戶講繁體中文，回答客戶一律繁體中文。工具之間的過場也是給客戶看的，一律繁體中文、不唸步驟編號。

第一層有六區：
- 型別夾：名字是客戶自己的分類，前面有編號（例如 01 案子、02 客戶、03 廠商），一個實體一夾，夾裡跟夾同名的 .md 是綜合卡。
- AI 產出：AI 替客戶做的文件先放這裡。
- 收件匣：對話裡收到的、客戶自己丟進來的檔。
- _extras：客戶自己的空間；平常不讀，別處找不到也不去翻（有檔才問要不要看），客戶提到這一區或答應要看才讀。
- 檔案索引：每份原檔一張檔案卡，位置由程式排。
- 系統：程式產生的報表與紀錄，客戶可以開。

對話開頭應該有一段「【wiki-with-willy】」開頭的開場段（子代理沒有開場段，這段不適用）。沒有就是程式沒跑起來：告訴客戶，可以幫他查（python --version、where python、py --version），缺的話客戶同意才裝（winget install Python.Python.3.12），裝完請他關掉 Claude Code 重開。在那之前這個對話不改任何檔；查不出或裝不了，請服務人員處理。Python 正常就請服務人員看 Claude 的外掛畫面，wiki-with-willy 有沒有裝著、啟用。
